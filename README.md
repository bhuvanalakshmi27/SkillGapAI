# 🚀 SkillGap AI

### 🎯 AI-Powered Career Readiness & Skill Gap Analysis Platform for Students

> **Know your skills. Identify your gaps. Build the right skills. Become career-ready.**

SkillGap AI is an intelligent career-readiness platform designed for students to understand their current skills, identify the gap between their skills and a target career role, and receive personalized guidance to improve their career readiness.

Instead of simply listing skills, SkillGap AI combines **skill assessments, mini tests, project evidence, resume analysis, job description analysis, learning roadmaps, and AI-powered recommendations** into one personalized workspace.

---

## 🌟 Why SkillGap AI?

Students often learn many technologies but do not know:

- ❓ Which skills are actually required for their target career?
- 📊 How strong are their current skills?
- 🎯 Which skills should they improve first?
- 🧩 What is missing between their current profile and a target role?
- 📄 Does their resume clearly show their actual skills?
- 💼 Does their profile match a particular job description?
- 🛠️ Which projects can help them demonstrate missing skills?
- 📚 What should they learn next?

### 💡 SkillGap AI brings these answers together in one platform.

---

# ✨ Key Features

## 👤 1. Student Profile

Create and maintain a personalized career profile containing:

- 👩‍💻 Student information
- 🎓 College
- 📚 Branch
- 🎯 Target career role
- 🛠️ Technical skills
- 📅 Graduation year

---

## 🎯 2. Career Goal & Target Role

Choose a target career role such as:

- 💻 Frontend Developer
- ⚙️ Backend Developer
- 🚀 Full Stack Developer
- 🐍 Python Developer
- ☕ Java Developer
- 📊 Data Analyst
- ☁️ Cloud Engineer
- 🔧 DevOps Engineer
- 🔐 Cybersecurity

The selected role becomes the foundation for personalized skill analysis.

---

## 📊 3. Skill Gap Analysis

SkillGap AI compares:

**Target Role Requirements ↔ Student's Current Skills**

It identifies:

- ✅ Skills meeting the required level
- ⚠️ Skills with a gap
- 🔴 High-priority skill gaps
- 🟡 Medium-priority skill gaps
- 🟢 Low-priority skill gaps
- ❓ Skills that have not been assessed

This helps students focus on the skills that matter most.

---

## 🧠 4. Skill Confidence Score

Skill confidence is calculated using multiple sources of evidence.

### Current model:

**40% Self Assessment + 60% Mini Test**

This produces a more meaningful skill-confidence indicator instead of relying only on what the student claims.

---

## 📝 5. Mini Skill Tests

Students can test their knowledge through skill-specific MCQ assessments.

Currently supported areas include:

- HTML
- CSS
- JavaScript
- React
- Python
- Java
- SQL
- Git

### 📈 Skill Classification

| Score | Classification |
|---|---|
| 0–39 | 🌱 Beginner |
| 40–69 | 📚 Developing |
| 70–84 | 💪 Intermediate |
| 85–100 | ⭐ Strong |

> These classifications are project-defined indicators for learning guidance and are not professional certifications.

---

## 🔥 6. Priority-Based Skill Gaps

Not every skill gap has the same importance.

SkillGap AI prioritizes gaps based on:

- 📉 Size of the skill gap
- 🎯 Importance of the skill for the target role

This helps answer:

> **"What should I learn first?"**

---

## 🤖 7. AI Skill Gap Explanation

AI-generated explanations help students understand:

- Why a skill is important
- Why the skill is currently considered a gap
- What concepts should be learned
- How the skill is used in the target role
- What practical steps can improve the skill

---

## 📚 8. Personalized Learning Roadmap

SkillGap AI generates a weekly learning roadmap based on:

- 🎯 Target career role
- 📊 Skill gaps
- 🔥 Skill priorities
- 🧠 Assessment results
- 📈 Skill confidence

The roadmap provides:

**LEARN → PRACTICE → BUILD → COMPLETE → NEXT WEEK**

Each week can include:

- 📖 Learning objectives
- 📌 Topics to study
- 🧪 Practice tasks
- 🛠️ Mini project
- ⏱️ Estimated learning time

---

## 💡 9. AI Project Recommendations

Instead of only telling students what they are missing, SkillGap AI recommends projects that can help them **build and demonstrate those skills**.

Recommendations can include:

- 🏗️ Project idea
- 📈 Difficulty level
- ⏱️ Estimated effort
- 🛠️ Recommended technologies
- 🎯 Related skill gaps
- 💼 Target-role relevance

---

## 📁 10. Project Evidence

Students can record projects that demonstrate their skills.

Project evidence helps connect:

**Skill → Project → Practical Evidence**

This provides stronger support for a student's skill profile.

---

## 📄 11. Resume Analysis

Upload a resume and analyze it against the student's career profile.

The system can identify:

- 🛠️ Skills detected
- 🔑 Important keywords
- 🎓 Education
- 💼 Experience
- 🏗️ Projects
- 🏆 Certifications
- ⚠️ Skills not clearly represented

> Missing from a resume does **not** mean the student does not have the skill. It means the resume may not clearly provide evidence for it.

---

## 🔄 12. Resume ↔ Skill Profile Consistency

SkillGap AI compares the student's:

**Recorded Skills ↔ Resume Evidence**

This helps students understand whether their resume clearly represents their actual profile.

---

## 💼 13. Job Description Analyzer

Paste a job description and analyze:

- 🎯 Job title
- 🛠️ Required skills
- 🔑 Important keywords
- 📋 Experience requirements
- ✅ Matching skills
- ❌ Missing skills
- 🔥 Priority gaps
- 📚 Recommended preparation

This helps students prepare for a specific job opportunity.

---

## 📈 14. Career Readiness Dashboard

The Career Readiness Dashboard provides a preparation indicator based on recorded activity and evidence.

### Readiness areas include:

- 🧠 Skill Readiness — **35%**
- 📝 Assessment Coverage — **20%**
- 🛠️ Project Evidence — **15%**
- 📄 Resume Readiness — **15%**
- 📚 Learning Progress — **15%**

The system also highlights:

- 💪 Strengths
- 🔥 Priority improvement areas
- 🎯 Recommended next actions
- 📊 Skill confidence
- 📈 Learning activity

> ⚠️ Career readiness is a preparation indicator, **not a guarantee of employment**.

---

## 📅 15. Weekly Progress Tracking

Track actual learning activity over time.

The system records activities such as:

- 📝 Assessments
- 🧪 Mini tests
- 📚 Roadmap updates
- 🛠️ Projects
- 📄 Resume analysis
- 💼 Job description analysis
- 🤖 AI recommendations

Students can monitor their learning progress through:

- 📊 Weekly activity
- 📈 Skill confidence trends
- 🕒 Recent activity history
- ✅ Completed projects
- 📚 Roadmap progress

---

## 🔐 16. Secure Authentication

SkillGap AI uses:

- 🔑 JWT authentication
- 🔒 Password hashing with bcrypt
- 🛡️ Protected backend routes
- 👤 User-specific data access
- 🔐 Server-side API credentials

Sensitive API keys are stored in environment variables and are **not exposed to the frontend**.
